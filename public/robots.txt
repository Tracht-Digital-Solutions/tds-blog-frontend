# Every group below is INDEPENDENT: a crawler obeys only the group that names
# it, and ignores the "*" group entirely. So every Disallow has to be repeated
# in each group — that is why this file is more verbose than it looks like it
# needs to be.
#
# /og/ is deliberately NOT disallowed. It used to be, in every group, which
# blocked the site's own social images: `/og/{lang}/{slug}.png` is the
# `og:image` of every article and the `image` of its BlogPosting. A crawler
# honouring robots.txt could not fetch the picture the page told it to use, so
# shares rendered without a preview and the article image was unusable as a
# rich result. The endpoint renders public article metadata only — there is
# nothing behind it to keep out of an index.
